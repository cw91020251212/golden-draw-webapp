# 金球時光 · 3D 攪珠遊戲

一個以瀏覽器執行的 3D 攪珠娛樂模擬器，使用原生 HTML、CSS、JavaScript 與 Three.js。每注由瀏覽器安全隨機源抽出七個不重複號碼；結果僅供娛樂，不是開獎預測或投注服務。

## 本機預覽

在本資料夾執行：

```sh
python3 -m http.server 8000
```

然後開啟 `http://localhost:8000`。需要透過 HTTP(S) 網址提供網站；直接用 `file://` 開啟不支援完整功能。

## 分享與安裝

頁首「分享」會呼叫裝置原生分享功能；不支援時會複製目前網址。要讓別人打開和安裝，先把網站部署到 HTTPS 網址（例如 GitHub Pages 或 Cloudflare Pages），再從手機瀏覽器選「加入主畫面／安裝應用程式」。網站已附有 Web App manifest、192/512 圖示及 maskable 圖示。

目前未加入離線快取；安裝為主畫面捷徑後，首次載入及使用仍需要網絡連線。

## 專案檔案

網站檔案位於根目錄，`app.js` 是應用邏輯；Three.js runtime、音樂和 PWA 圖示均直接包含。此儲存庫只包含正式網站檔案，不包含測試截圖、QA 工具、歷史版本補丁或使用者提供的參考照片。
