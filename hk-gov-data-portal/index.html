七大途徑

同一份資料可能同時以檔案、API、地圖服務幾種方式出現——先認途徑，再對應用途。

目錄

開放數據目錄

DATA.GOV.HK 集中發佈各局／署數據集：主題分類、下載連結、更新頻率、資料字典。

入口：data.gov.hk

API

程式介面

CKAN 元數據 API、歷史檔案 API、各署專用 REST／JSON／RSS——適合系統對系統讀取。

入口：API 說明

座標

座標系統與轉換

WGS84、HK1980 地理／格網、UTM；地政總署提供即時座標轉換 API。

入口：大地測量轉換

地址

地址／GeoAddress

以自由文字或 19 字元 GeoAddress 查標準地址、樓宇單位同座標，統一跨系統位置識別。

入口：als.gov.hk

空間

共用空間數據基建

CSDI Portal：地圖 API、資料集 API（WFS／WMS／ArcGIS）、目錄服務、位置搜尋。

入口：portal.csdi.gov.hk

物件

設施／物件位置

政府設施、道路、物業、監測站等空間圖層；可用位置搜尋或下載向量／地圖服務。

入口：map.gov.hk

服務

實時與主題服務

天文台天氣、運輸署交通、環境監測等持續更新端點——多數掛喺 DATA.GOV.HK 或部門網站。

入口：各主題數據集頁

1. 數據目錄與檔案

最闊嘅入口：先搜主題，再睇資源格式同授權。

DATA.GOV.HK

  • 主題分類：運輸、天氣、地理土地、房屋、環境、醫療……
  • 常見格式：CSV、JSON、XML、GeoJSON、KML、FGDB、PDF 字典
  • 每項資源通常標示：提供部門、更新頻率、API 有無、資料字典連結
  • 語言路徑：/tc/ 繁中、/en/ 英文、/sc/ 簡中

開放數據入口 歷史數據說明

要記住

  • 目錄頁嘅「API」可能係元數據 API，唔等於數據本身有 REST。
  • 同一數據集可有多個資源（中／英、即時／歷史、唔同格式）。
  • 使用前睇提供部門條款同資料字典；精準測量／法律用途可能唔適用。

2. API 途徑

分「搵數據」同「讀數據」兩層——唔好混淆。

CKAN 元數據 API

列出同查詢 DATA.GOV.HK 上數據集嘅 metadata（名稱、資源 URL、描述）。

GET https://data.gov.hk/tc-data/api/3/action/package_list
GET https://data.gov.hk/tc-data/api/3/action/package_show?id=<dataset_id>
GET …/group_list　…/group_show

只支援指定 GET；詳見 CKAN API 指引。

歷史檔案 API

按日期、類別、提供者以程式列出／下載舊檔。

GET https://app.data.gov.hk/v1/historical-archive/list-files
    ?start=YYYYMMDD&end=YYYYMMDD&…

API Specification

部門／主題 Open API

掛喺個別數據集下，例如天文台天氣報告、交通快拍等；格式同限流以該署文件為準。

  • 天文台：天氣 Open Data API 文件（PDF）
  • 運輸署：交通數據集（影像、流量、快拍位置等）
  • 其他：環境、屋宇、規劃……以目錄搜尋「API」篩選

CSDI 地理空間服務

  • OGC WFS — 向量查詢／下載
  • OGC WMS — 地圖影像
  • ArcGIS REST — ESRI 結構服務
  • OGC Catalogue — 目錄發現
  • Map APIs — 底圖／應用嵌入

GeoSpatial Services 說明

3. 座標途徑

香港項目成日要喺 WGS84 同 HK1980 之間轉換——呢個係獨立途徑，唔係「又一個數據集」。

常用系統

  • WGS84 地理（緯度／經度）— GPS、多數網圖預設
  • HK1980 地理 — 本地大地基準
  • HK1980 格網（Northing／Easting，米）— 工程、地籍常用
  • UTM Grid／Grid Reference — 區域投影

轉換 API（地政總署）

GET http://www.geodetic.gov.hk/transform/v2/
    ?inSys=wgsgeog&lat=22.3&long=114.15

參數：inSys / outSys（wgsgeog、hkgeog、hkgrid、utmgrid、utmref）、lat、long、n、e、h、zone 等。

數據集頁 Data Dictionary

使用界線

  • 只適用香港範圍內座標。
  • 官方提醒：唔應用於要求精密定位嘅用途；基準轉換唔會提高精度。
  • 法律／工程測量應諮詢註冊土地測量師。
  • CSDI 圖層常見 EPSG:4326 或 EPSG:2326（HK1980 Grid）。

4. 地址與位置識別

文字地址亂、別名多——用標準服務對齊「同一個地方」。

Address Lookup Service（ALS）

自由文字搜樓名、街道門牌、屋苑座數；可回傳中英地址同相關欄位。

GET https://www.als.gov.hk/lookup?q=<地址關鍵字>

常用參數：n（最多筆數）、t（分數容差）、b（基本搜尋）、3d（樓層／單位）。

GeoAddress Lookup

19 字元 GeoAddress 係跨系統共用參考（同一地點可有多種文字寫法）。

GET https://www.als.gov.hk/galookup?ga=<19字元GeoAddress>

ALS 數據集 · 數碼辦提供

Location Search API（地圖）

按地址、樓宇、地名、設施名搜位置——偏地圖應用。

GET https://www.map.gov.hk/gs/api/v1.0.0/locationSearch?q=<關鍵字>

注意限流；版本號可能更新。API 文件

5. 物件位置與空間圖層

「物件」＝設施、道路中心線、監測站、地段……有幾何嘅資料。

點樣攞到物件

  1. 喺 CSDI／DATA.GOV.HK 搜主題（例如交通流量站、政府場地）。
  2. 睇資源：FGDB／KML／GML／GeoJSON 下載，或 GeoSpatial Service 連結。
  3. 用 WFS 按範圍／屬性過濾；用 WMS 只係睇圖。
  4. 需要「呢個名喺邊」→ Location Search／ALS，再對圖層。

相關入口

  • CSDI Portal — 空間數據目錄同 API
  • 地理資訊地圖 — 公眾地圖同開發 API
  • 運輸署 Traffic Flow Census 等 — 站線、道路中心線等空間檔

下一步清單

第一步「知道」之後，建議按呢個次序推進——仍然可以未即用。

  1. 圈定業務問題 例如：顯示診所位置、對齊市民地址、轉工程座標。
  2. 喺目錄搜 3–5 個候選數據集 記低 dataset id、提供部門、更新頻率、有無字典。
  3. 標註你需要邊種途徑 只下載／要 API／要地圖服務／要座標轉換——可以多過一種。
  4. 核對座標同識別鍵 WGS84 定 HK1980？有無 GeoAddress？物件 ID 可唔可以跨系統？
  5. 試一個最小讀取 手動下載一個檔，或打一次 package_show／一個查詢 API。
  6. 先寫「途徑說明」再寫程式 邊個入口、邊個負責人、限制同授權——方便審批同交接。

呢頁係地圖，唔係引擎。收齊途徑之後，先至值得談接駁同產品化。
