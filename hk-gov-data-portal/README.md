# 港府數據途徑圖

發現導向嘅靜態 HTML 頁：盤點香港政府開放數據嘅主要途徑（目錄、API、座標、地址、空間物件、地圖服務、實時服務）。**目的係先知道有甚麼，未必即用。**

## 本機預覽

```sh
cd hk-gov-data-portal
python3 -m http.server 8080
```

打開 `http://localhost:8080`。

## 內容範圍

| 途徑 | 官方入口例子 |
|------|----------------|
| 開放數據目錄 | [data.gov.hk](https://data.gov.hk/tc/) |
| CKAN／歷史 API | [API 說明](https://data.gov.hk/tc/help/api-spec) |
| 座標轉換 | [geodetic.gov.hk](https://www.geodetic.gov.hk/en/gi/transformation.htm) |
| 地址／GeoAddress | [als.gov.hk](https://www.als.gov.hk/) |
| CSDI 空間服務 | [portal.csdi.gov.hk](https://portal.csdi.gov.hk/?lang=zh-hk) |
| 地圖／位置搜尋 | [map.gov.hk](https://www.map.gov.hk/) |

本頁為非官方彙編；連結與條款以政府網站為準。
